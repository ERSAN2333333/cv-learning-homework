Q1：解释增加模型深度与扩大输入分辨率的不同影响。
【订正答案】
增加模型深度通常会增加参数量和计算量，让模型能够组合更多层次的特征，
但不保证效果更好：数据不足时可能过拟合，过深也可能增加优化难度。
过拟合是泛化问题；优化退化是更深模型连训练表现都可能变差，两者不是同一回事。

提高输入分辨率可能保留更多小物体、纹理和边缘细节，同时增加计算量和中间特征内存。
但把低清图片简单放大不会凭空增加真实细节。
参数量是否变化取决于模型结构：当前ResNet50使用自适应池化，输入分辨率变大，
参数量可以保持不变；若直接展平后连接全连接层，则可能需要改变该层参数量。
概括：加深模型改变处理信息的层次，提高分辨率改变输入的空间采样细致程度。

Q2：两层3×3、stride=1、无膨胀，单点输出理论感受野多大？
【订正答案】
第一层为3×3，第二层为5×5。
从输入单点的感受野大小1开始，每层3×3、步长1的卷积使感受野边长增加2：
1 → 3 → 5，因此最终为5×5，而不是把两个3直接相乘得到9×9。
这里讨论理论感受野；边界位置可能有部分范围落在padding而非真实图像上。

Q3：验证用随机裁剪且按批均值平均，分别怎么修？
【订正答案】
（1）验证预处理：
随机裁剪会使同一张验证图片在不同轮次出现不同内容，指标变化不再只反映模型变化。
将验证改为确定性预处理，如固定Resize和CenterCrop，并保持归一化规则一致。
不是删除所有预处理，而是避免验证输入随机变化。合理的随机裁剪可用于训练增强。
验证时同时使用model.eval()和torch.no_grad()。

（2）平均loss：
每批平均loss直接相加再除以批次数，给不同大小的批次赋予了相同权重。
尾批样本较少时，这不一定等于全部样本的平均loss，偏差可能向上也可能向下。
各批样本数相同或各批平均loss相同时，两种结果可以相等。
对于题设中每批loss是等权样本平均的情况，应按实际样本数加权：

total_loss = 0.0
total_num = 0
model.eval()
with torch.no_grad():
    for images, labels in val_loader:
        images, labels = images.to(device), labels.to(device)
        logits = model(images)
        loss = loss_fn(logits, labels)
        size = labels.size(0)
        total_loss += loss.item() * size
        total_num += size
assert total_num > 0
average_loss = total_loss / total_num

注意：若batch是(images, labels)，len(batch)是2，不是图片数量。
