1.预训练是一个别人已经训练好设置好参数和超参数的模型，这其中包含了模型主干和分类头，将预训练模型用自己的数
据集上是迁移学习，可以选择冻结模型主干只训练分类头，也可以选择将整个网络都不冻结全部用来训练。冻结就是
冻结某些结构的参数，取消这部分的梯度计算，微调就是修改某些结构比如分类头，微调一般需要冻结别的结构。

2.首先可以使用model.name_modules方法，找出那些module.training，以此来确认那些模块处于训练模式或者
测试模式，这里需要关注BN层，BN层只有处在eval模式下才不会改变运行统计。冻结主干只是将主干设置为不参与梯度
计算，但是BN层的运行统计依然会改变。
我设置的方法是在dataset中定义编号和类别的对应关系，这里如果模型输出的类名与编号不对应，首先应该检查模型
使用的数据加载器的数据集里面这个对应关系是否正确，其次应该检查在模型输出logits时映射类名的关系是否正确。

【订正】第1项：概念关系
预训练：模型已经在其他数据上学习了一组参数，但原来的超参数不一定适合新任务。
主干负责提取特征，分类头负责把特征映射到类别。
迁移学习：利用已有模型的知识完成新任务。
冻结：设置requires_grad=False，使指定参数不计算梯度、不参与常规梯度更新；不会自动切换BN模式。
微调：用新数据继续训练已有模型的部分或全部参数，不一定冻结其他层。
替换分类头是结构调整，随后训练分类头才是参数学习。

【订正】第2项：定位错误
BN：使用model.named_modules()，查看BN层的module.training。验证时应为False；只训练分类头时，主干BN也应保持eval。
requires_grad=False不会阻止train模式下的BN更新运行统计；model.eval()才会让常规BN使用已有运行统计。
类别表：核对训练时保存的类别顺序、当前Dataset标签编号，以及预测编号到类别名称的映射，三者应一致。
检查BN的简单写法：
for name, module in model.named_modules():
    if isinstance(module, torch.nn.BatchNorm2d):
        print(name, module.training)

【订正】第3项：独立重载与预测
下面是重载参考代码：先按原实验的验证预处理建立val_loader，best.pth需改为本实验权重的实际路径。
示例假设检查点保存了完整模型参数model和类别表classes，且模型结构与原实验一致。

import torch
from torchvision.models import resnet50

checkpoint = torch.load("best.pth", map_location="cpu", weights_only=False)
classes = checkpoint["classes"]
assert classes == val_loader.dataset.name_list, "类别顺序不一致"
model = resnet50(weights=None)
model.fc = torch.nn.Linear(model.fc.in_features, len(classes))
model.load_state_dict(checkpoint["model"])
model.eval()

image, label = next(iter(val_loader))
with torch.no_grad():
    pred_label = model(image.cpu()).argmax(dim=1)
for true_id, pred_id in zip(label.cpu().tolist(), pred_label.tolist()):
    print(f"真实标签：{classes[true_id]}，预测标签：{classes[pred_id]}")

一项不能归因的观察：准确率提高了，但预处理或训练设置也发生变化，因此不能将提升单独归因于预训练。
应使用实际发生的变化描述实验；没有改变的设置不要写成已改变。
